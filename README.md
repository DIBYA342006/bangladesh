🌟 About the Project

On March 26, 1971, the nation of Bangladesh proclaimed its independence, culminating in a nine-month war of liberation that ended in victory on December 16, 1971.

This website serves as a digital archive and tribute to:

Commemorate the 3 million martyrs (Shaheed) and freedom fighters (Muktijoddha).

Educate younger generations and global audiences about the Language Movement of 1952, the Six-Point Movement of 1966, the historic March 7 Speech, and the events of 1971.

Provide accessible, respectful, and well-researched historical media and documentation.

✨ Key Features

Interactive Timeline (1952–1971): Explore pivotal moments—from the Language Movement to Victory Day (Bijoy Dibos).

The Historic March 7 Speech: Audio, video, and verified transcriptions of Bangabandhu Sheikh Mujibur Rahman's UNESCO-recognized address.

Bir Sreshtho & National Heroes: Dedicated profiles of the seven recipients of the highest military award and key civilian leaders.

Interactive Sector Map: Visual map detailing the 11 wartime operational sectors and commanders.

Digital Archive & Gallery: Curated historical photographs, radio broadcasts (Swadhin Bangla Betar Kendra), newspaper clippings, and document scans.

Multilingual Support: Fully accessible in both Bengali and English.

Responsive & Accessible Design: Optimized for mobile, tablet, and desktop viewing following WCAG accessibility guidelines.

🚀 Getting Started

Prerequisites

Node.js (v18.0.0 or higher recommended)

npm, yarn, or pnpm

Installation

Clone the repository:

git clone https://github.com/your-username/bangladesh-independence-web.git
cd bangladesh-independence-web


Install dependencies:

npm install
# or
yarn install


Running Locally

Start the development server:

npm run dev
# or
yarn dev


Open http://localhost:3000 in your browser to view the application.
